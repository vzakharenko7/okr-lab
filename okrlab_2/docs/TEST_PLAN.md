# Тест-план: логіка гри «Рулетка» (Form1)

## 1. Об'єкт тестування
Клас `Form1` проєкту `okrlab_2`: баланс, ставки, обчислення виплат (`CalculateSpinPayout`), дані колеса.
Код гри не змінювався — тести викликають його як є (приватні поля читаються через reflection).

## 2. Підхід
- Модульне тестування, xUnit, проєкт `okrlab_2.Tests` (`net8.0-windows`, потрібен Windows).
- Техніки: класи еквівалентності, аналіз граничних значень, таблиця рішень (виплати).
- `MessageBox` про нестачу коштів автоматично закривається допоміжним таймером.

## 3. Вимоги
| ID | Вимога |
|----|--------|
| REQ-1 | Початковий баланс — 1000 |
| REQ-2 | Успішна ставка списується з балансу; ставки на одну позицію складаються |
| REQ-3 | Фішка більша за баланс / нульовий баланс — відмова; ставка під час обертання ігнорується |
| REQ-4 | Виплата: число ×36, дюжини і колонки ×3, решта ×2; нуль програшний для зовнішніх ставок |
| REQ-5 | Дані колеса: 18 червоних чисел, 37 чисел 0–36 |

## 4. Не покривається
- Ставка 0 і від'ємна ставка: в інтерфейсі неможливі (розмір ставки = номінал фішки 10/25/50/100/500).
- Анімація колеса, вікна `Form2–Form4` (UI) — перевіряються вручну.

## 5. Запуск (Windows, .NET 8 SDK)
```bash
cd okrlab_2
dotnet test okrlab_2.Tests
```
У Visual Studio: **Test → Run All Tests**.
